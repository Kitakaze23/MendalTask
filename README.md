# MendalTask


Один файл `index.html`, без сборки. Работает в браузере и как Telegram Mini App.

## Что умеет
- Доска: **Бэклог → To Do → In Progress → Done**. Перетаскивание мышью, на телефоне стрелки ‹ › на карточке.
- Фильтр по исполнителю (Василий, Соня, Паша, «Без исполнителя») и по категории, на доске и в архиве. Список людей и категорий меняется в настройках.
- Карточка задачи: название, описание, исполнитель, категория, срок (просроченные подсвечиваются красным), статус, спринт.
- **Завершённые**: отдельная вкладка с архивом выполненных задач, поиск и фильтр по спринту.
- **Настройки**: длительность спринта, создание/старт/завершение/переименование/удаление спринтов, синхронизация, экспорт/импорт JSON.
- При завершении спринта незавершённые задачи уходят в следующий запланированный спринт или в бэклог.

## 1. Выложить на GitHub Pages
1. Создайте репозиторий (уже создан: MendalTask), загрузите `index.html` в корень.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Через минуту трекер откроется по адресу https://kitakaze23.github.io/MendalTask/.

Без шага 2 и 3 ниже данные хранятся только в браузере (localStorage), на каждом устройстве свои.

## 2. Синхронизация (Supabase, бесплатный тариф)
GitHub Pages отдаёт только статические файлы, поэтому данные хранятся в Supabase.
1. Зарегистрируйтесь на supabase.com, создайте проект.
2. SQL Editor → вставьте содержимое `supabase.sql` → Run.
3. Project Settings → API: скопируйте **Project URL** и **anon public key**.
4. В начале `index.html` заполните `TRACKER_CONFIG` (supabaseUrl, supabaseKey, boardId) и загрузите файл заново.

Синхронизация раз в 15 секунд и при возврате на вкладку. Изменения сливаются по задачам: если двое правят разные задачи одновременно, ничего не теряется; при правке одной и той же задачи побеждает последняя.

⚠️ anon key виден в коде страницы. Защита держится на неочевидном ID доски, поэтому не используйте `main`, если репозиторий публичный.

## 3. Telegram-бот
1. В @BotFather: `/newbot` → получите бота.
2. `/mybots` → ваш бот → Bot Settings → Menu Button → укажите URL GitHub Pages и название кнопки «Трекер».
3. Откройте бота: кнопка меню открывает трекер внутри Telegram, в цветах темы Telegram. Исполнитель в новой задаче подставляется из имени пользователя Telegram.

Сервер для бота не нужен.
